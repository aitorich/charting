CISD — Change in State of Delivery

Reversal confirmation on the aligned LTF. Identify the consecutive run of bearish (or bullish) candles terminating at or before the HTF window's extreme. Anchor = open of the oldest candle in that run. CISD fires when a candle closes through that anchor.

1. Bullish CISD aligned LTFconsecutive run

Bullish CISD. Inside the HTF window, find the LTF bar that prints the lowest low. Capture the full consecutive run of bearish candles that terminates at/before that low. Anchor = open of the oldest candle in the run (top of the displacement leg). CISD fires when an LTF bar's close crosses above the anchor.

2. Bearish CISD aligned LTFconsecutive run

Bearish CISD. Capture the full consecutive bullish run ending at/before the highest high. Anchor = open of the oldest bullish in that run (bottom of the displacement leg). CISD fires when an LTF bar's close drops below the anchor.

3. Low bar is bullish — capture the run before it walk back

Edge case. When the low-print bar is bullish, walk backward through the bars until the run is reached, then cover the entire consecutive bearish run. Anchor = open of the oldest red (top of run), regardless of how many candles between the run and the low.

4. Single or consecutive — same rule oldest = anchor

Single vs consecutive — same rule. Whether the run has 1 candle or many, cover the entire run. Anchor is always the open of the oldest candle (the highest open, at the top of the down-leg for bullish; lowest open, at the bottom of the up-leg for bearish).
