SMT — 4HR Quarters within Daily Block

Apply on a 4HR chart. Each daily candle = 6 × 4HR quarters: Q1 (18–22 ET) · Q2 (22–02) · Q3 (02–06) · Q4 (06–10) · Q5 (10–14) · Q6 (14–18). Detect SMT divergence between correlated pairs (NQ/YM, EURUSD/GBPUSD, XAUUSD/XAGUSD) within and across daily blocks.

Concept — 1 Daily Candle = 6 × 4HR Quarters

The daily candle aggregates Q1–Q6. Open = Q1 open, Close = Q6 close, High/Low = max/min wick across the 6 quarters.

Within-Day Bullish SMT — Q3

On Q3, Symbol A takes a low below the Q1+Q2 reference wick low; Symbol B holds. Bull SMT line wick-to-wick on the diverging side.

Within-Day Bearish SMT — Q4

On Q4, Symbol A takes a high above Q1+Q2+Q3 reference wick high; Symbol B doesn't. Bear SMT line wick-to-wick.

Reference high Bear SMT line

Cross-Day Bullish SMT — Q1 vs prev day Q1..Q6 range

Today's Q1 sweeps below the prev day's MIN low (across Q1..Q6) — only on one symbol. SMT line spans the day boundary, anchored at whichever prev Q held the min.

SMT Validity Checklist

  • 4HR chart only — each candle is one 4HR quarter
  • Reference = wick extreme of prior Q1..Q(n-1) within the same daily block
  • Cross-day reference = MAX H / MIN L across the previous day's Q1..Q6
  • Exactly one symbol takes the reference; the partner does NOT on the same 4HR candle
  • SMT line drawn wick-to-wick from anchor bar to current bar on the chart's symbol
  • Each level consumed once per block — no duplicate fires
