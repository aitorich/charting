SMT — Daily Quarters within Weekly Block

Apply on a Daily chart. Each weekly candle = 5 daily quarters: Q1 Mon · Q2 Tue · Q3 Wed · Q4 Thu · Q5 Fri. Detect SMT divergence between correlated pairs (NQ/YM, EURUSD/GBPUSD, XAUUSD/XAGUSD) within and across weekly blocks.

Concept — 1 Weekly Candle = 5 Daily Quarters

The weekly candle aggregates Mon–Fri. Open = Mon open, Close = Fri close, High/Low = max/min wick across the 5 daily candles.

SMT Validity Checklist

  • Daily chart only — each candle is one daily quarter
  • Reference = wick extreme of prior Q1..Q(n-1) within the same weekly block
  • Cross-week reference = previous block's Q5 wick extreme
  • Exactly one symbol takes the reference; the partner does NOT on the same daily candle
  • SMT line drawn wick-to-wick from anchor bar to current bar on the chart's symbol
  • Each level consumed once per block — no duplicate fires
